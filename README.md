# 考研择校 RAG 系统

带溯源机制 + 结构化数据校验的 RAG 系统，核心目标：降低大模型幻觉，体现工程化思维

## 核心亮点

- **四层防线降低幻觉**：检索质量 → 生成约束 → 数据校验 → 置信度拒答
- **混合检索 + Reranker**：BM25 + 向量检索 + RRF 融合 + 精排，工业级检索方案
- **答案溯源机制**：每句话标注来源，用户可点击查看原始文档
- **结构化数据校验**：自动比对回答中的数字与真实数据，防止关键信息出错
- **工程化设计**：前后端分离、配置管理、模块化架构

## 技术栈

| 组件 | 选择 | 理由 |
|------|------|------|
| LLM | DeepSeek API | 性价比高，中文效果好，兼容 OpenAI 格式 |
| Embedding | BAAI/bge-small-zh-v1.5 | 中文专用，本地运行免费，效果好 |
| Reranker | BAAI/bge-reranker-base | 中文精排模型，本地运行 |
| 向量数据库 | ChromaDB | 轻量级，Python 原生，上手快 |
| BM25 | rank_bm25 | 纯 Python，无需外部服务 |
| 后端 | FastAPI | 现代、高性能、自动文档 |
| 前端 | Streamlit | 快速构建数据应用界面 |

## 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 配置 API Key
# 编辑 .env 文件，填入你的 DeepSeek API Key

# 数据入库
python -m backend.services.ingestion

# 启动后端（端口 8000）
uvicorn backend.main:app --reload

# 启动前端（新开终端）
streamlit run frontend/app.py
```

## 四层防线架构

```
用户提问
    │
    ▼
┌─────────────────────────────────────┐
│  第1层：检索质量保障                 │
│  BM25 + 向量混合检索 → RRF融合      │
│  → Reranker精排 → 过滤低相似度结果   │
├─────────────────────────────────────┤
│  第2层：生成约束                     │
│  System Prompt 强制引用标注          │
│  每句话标注来自哪个文档               │
├─────────────────────────────────────┤
│  第3层：结构化数据校验                │
│  正则提取数字 → 与JSON标准答案比对    │
│  不一致的数字标红警告                 │
├─────────────────────────────────────┤
│  第4层：置信度评估 + 拒答             │
│  高(>0.8) / 中(0.5-0.8) / 低(<0.5)  │
│  低置信度直接回复"暂无相关信息"       │
└─────────────────────────────────────┘
    │
    ▼
带溯源标注 + 校验标记的回答
```
